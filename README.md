# ComfyUI 素材管理器

一个本地图形化的 ComfyUI **素材管理工具**：按你输出时做的文件夹分类来浏览图片 / 视频，
三分式查看每个文件的生成参数与正反提示词，并集中管理多目录下的模型文件。
只扫描你配置的目录，不接管、不移动任何文件，除非你主动操作。

> Python 3.10+ ｜ Flask ｜ 无前端依赖（单页自包含）｜ 本地运行

## ✨ 功能速览

| 视图 | 核心能力 |
|------|----------|
| 🖼 输出管理 | 文件夹树分类浏览图片/视频，三分式查看 PNG 内嵌参数与正反提示词，比例筛选、实时自动刷新、双击放大预览、删除/新建/打开文件夹 |
| 📦 模型管理 | 多目录扫描，类型 + 系列双层分类，用户备注、移动、删除，系列显示正则自定义 |
| ⚙️ 工作流管理 | 工作流解析（节点数/调用模型/LoRA/采样参数/提示词），缺失节点检测，笔记节点读取编辑，最近生成结果关联，复制/导出 JSON |

## 运行环境

- Windows / macOS / Linux 均可
- Python 3.10+
- 本机已安装并运行 ComfyUI（默认地址 `http://127.0.0.1:8188`，用于显示连接状态；未运行也不影响素材浏览）

## 安装与启动

**方式一：命令行启动（跨平台）**

```bash
cd comfyui-asset-manager
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:8000 即可使用。

**方式二：Windows 一键脚本（Windows 用户推荐）**

直接双击项目内的 **`启动服务.bat`**，脚本会自动：

1. 检测 Python（优先 `py`，其次 `python` / `python3`）；
2. 首次运行自动安装依赖（`pip install -r requirements.txt`，已装则跳过）；
3. 启动服务并自动打开浏览器 http://127.0.0.1:8000（已在运行则直接打开浏览器）。

停止服务：双击 **`停止服务.bat`**（结束占用 8000 端口的服务进程，不影响 ComfyUI 本身）。

> 首次启动若 `config.json` 不存在，界面目录为空：可在右上「目录设置」手动添加模型 / 输出 / 工作流目录，
> 或参考 `config.example.json` 复制为 `config.json` 后按需修改。

## 🖼 输出管理（默认页）

三分式布局，按你输出时建立的文件夹分类浏览：

- **左栏 · 文件夹**：自动扫描所有输出目录的完整**可折叠文件夹树**（三角展开 / 收起，默认全部收起，
  支持「全部展开 / 全部收起」按钮），每个文件夹标注图片 / 视频数量；支持**新建子文件夹**、**删除空文件夹**（二次确认）、
  **打开所在文件夹**（资源管理器）、目录设置（增删输出目录、**排除子目录**——如 `minimax_seg_cache`
  这类缓存目录配置后不扫描、不显示）。
- **中栏 · 文件**：当前文件夹内的文件缩略图网格（固定图宽、列数随窗口自适应、多余内容内部滚动），
  支持**按文件名搜索**、**时间排序**、**图片/视频筛选**、**常用比例多选筛选**（1:1 / 2:3 / 3:2 / 3:4 / 4:3 / 9:16 / 16:9 / 21:9 / 其他）；
  目录内容**实时自动检测**——ComfyUI 生成新文件后无需刷新页面即可看到；单击文件在右侧显示详情，**双击打开大图预览**。
- **右栏 · 详情（三分）**：
  - **左上 · 参数**：自动读取 PNG 内嵌的 ComfyUI 元数据——模型 / UNet / CLIP / VAE / LoRA、
    采样器 + 调度器、步数、CFG、种子、尺寸、批次、降噪，外加文件大小 / 修改时间 / 所在文件夹。
  - **左下 · 正反提示词**：正向 / 反向提示词全文，过长自动**折叠**（点击展开 / 收起）；
    元数据未存负向提示词时显式显示「未使用反向提示词」；**双击内容即可复制**。
  - **右 · 预览**：单图大图展示；**视频用原生播放器直接播放**；支持**删除**（二次确认）与打开文件夹。

> 截图、PS 另存等后处理会清除 PNG 元数据，这类图右侧参数区会提示"没有 ComfyUI prompt 元数据"，
> 但文件本身仍可正常浏览、预览与删除。

## 📦 模型管理（顶部导航「模型管理」）

- 首次启动自动检测：从运行中的 ComfyUI 进程读取安装目录、输出目录、工作流目录与
  `extra-model-paths` 配置，把全部模型根目录（含任意位置的外部模型目录）写入 `config.json`。
- **列表式浏览 + 双层分类**：
  - **类型**（紫色徽章）：按顶层文件夹分类（checkpoints / diffusion_models / clip / vae / loras…）；
  - **系列**（青色徽章）：读取二级子目录识别模型家族/系列，例如 `vae/A01Z_image/ae.safetensors`
    的系列是 `A01Z_image`（造相）、`krea2`（Krea）、`qwen`（千问）、`minimax_h3`（海螺）等。
  - 列表显示文件名、相对路径、类型、系列、大小、修改时间、所在磁盘；**主目录高亮标识**。
- **操作**：**备注**（点击弹窗给模型加自定义备注，金色显示在模型名下，可清除）、打开所在文件夹（资源管理器）、
  移动到其他类型目录、删除（两次点击确认）。
- **系列显示规则**（目录设置内）：可填**正则**让系列筛选只显示你自定义的系列（如 `^[A-Z]\d{2}`
  只保留 `A01Z_image` 这类），并可**排除列表**过滤掉 bbox / segm / ESRGAN 等系统自动带出的系列。
- **多目录**：模型目录可自由增删，「自动检测」一键重扫。

## ⚙️ 工作流管理（顶部导航「工作流」）

三分式布局，与输出管理一致：

- **左栏 · 工作流文件夹**：完整**可折叠文件夹树**（含层级与分支计数，默认全部收起 + 全部展开/收起按钮），
  点击任一文件夹即列出该分支下的全部工作流（默认选中根目录 = 全部工作流）；目录设置可增删工作流目录。
- **中栏 · 列表**：按名称自然排序、按时间最新/最早排序；每个条目显示所在路径与修改时间。
- **右栏 · 详情**（打开任意工作流自动解析，标签页按需切换）：
  - **文件信息**：格式（UI 工作流 / API 执行图）、**节点数**、大小、修改时间；
  - **调用模型**：工作流里用到的 Checkpoint / UNet / CLIP / VAE 及加载参数（CLIP 类型等）；
  - **LoRA**：所有 LoRA 及 model / clip 强度；
  - **采样参数**：采样器 + 调度器、步数、CFG、种子、降噪、尺寸（宽 × 高 × batch）；
  - **正反提示词**：全文展示，**双击复制**；
  - **笔记节点**：读取工作流内的 Note / MarkdownNote 官方节点，按节点逐个标签页展示，
    支持**直接编辑并保存回工作流**，Markdown 语法自动渲染；
  - **最近生成结果**：关联展示该工作流最近的输出图片，可快速回看生成效果；
  - **缺失节点检测**：对比当前 ComfyUI 已安装节点，标红提示哪些节点未安装（直接运行会报错）。
- **操作**：打开所在文件夹、**复制 JSON**、**导出 JSON**（下载完整工作流文件，可粘贴/导入回 ComfyUI 编辑器）、删除（两次确认）。
- **多目录**：工作流目录可自由增删，自动检测一键补齐。

> 说明：个别工作流使用特殊控件（如随机种子开关、多采样器并联）时，采样参数字段可能对不齐，
> 以实际工作流为准。

> 路径安全：删除 / 移动 / 新建 / 打开仅允许在已配置的模型 / 输出目录内进行，越界请求会被后端拒绝（403）。

## 配置说明（config.example.json）

复制 `config.example.json` 为 `config.json` 即可自定义：

| 字段 | 说明 |
|------|------|
| `model_dirs` | 模型根目录列表（可多个，支持 E/D 盘等任意位置） |
| `output_dirs` | 输出目录列表（ComfyUI 保存生成结果的位置） |
| `workflow_dirs` | 工作流目录列表（保存的 .json 工作流所在位置） |
| `output_excludes` | 输出目录下的排除子目录（缓存类目录，配置后不扫描不显示） |
| `series_filter.pattern` | 系列筛选正则（只保留你自定义的系列格式，如 `^[A-Z]\d{2}`） |
| `series_filter.exclude` | 系列排除列表 |
| `comfyui_host` | ComfyUI 服务地址（默认 `http://127.0.0.1:8188`，也可用环境变量 `COMFY_HOST` 覆盖） |

```

├── app.py                # Flask 后端：目录检测、文件夹树、输出/模型/工作流接口、参数元数据读取
```

## 常见问题

- **图片右侧提示"没有 ComfyUI prompt 元数据"**：图片经过截图 / PS 另存等后处理，PNG 内嵌参数被清除；文件本身仍可正常浏览。
- **ComfyUI 未启动能使用吗？** 能。服务与 ComfyUI 相互独立，素材浏览、参数读取、模型管理照常可用（仅连接状态徽章与依赖 ComfyUI 的检测功能不可用）。
- **端口被占用 / ComfyUI 不在 8188**：右上角「目录设置 / 连接设置」可修改 ComfyUI 地址，或配置 `comfyui_host` / 环境变量 `COMFY_HOST`。
- **删除的文件能找回吗？** 不能，删除为物理操作不可撤销；前端均有两次点击确认，文件夹删除仅限空文件夹。

## 注意事项

- 删除操作均需两次点击确认；文件夹删除仅限空文件夹（有文件的文件夹会被后端拒绝）。
- 服务与 ComfyUI 相互独立：ComfyUI 未运行时，素材浏览、参数读取、模型管理照常可用。
